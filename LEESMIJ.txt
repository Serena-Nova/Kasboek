Kasboek — versie 2026-10-12a

UPDATEN
Upload alle bestanden uit deze map over de oude heen in je GitHub-repository.
Je gegevens blijven gewoon staan (in je browser en Dropbox).

NIEUW IN DEZE VERSIE
- Labels (Idonea, Jordy, Gezin, Kind, Dieren — zelf aan te passen) naast categorieën.
  Een transactie kan meerdere labels hebben.
- Meerdere rekeningen: alles samen, of per rekening apart bekijken.
- Overboekingen tussen jullie eigen rekeningen tellen niet als uitgave.
- Per rekening een standaardlabel (bijv. alles van Jordy's rekening = Jordy).
- Labels via regels, per transactie, of in één keer voor een hele selectie.
- Rekening toevoegen zonder CSV (alleen om overboekingen te herkennen).
- Nieuwe categorie Huisdieren.

ONLINE ZETTEN (eerste keer)
1. Maak op GitHub een nieuwe repository, bijvoorbeeld "kasboek" (account SerenaNova).
2. Upload alle bestanden uit deze map (niet de map zelf) naar de hoofdmap van de repository.
3. Settings → Pages → Branch: main, map: / (root) → Save.

DROPBOX KOPPELEN (eenmalig)
1. https://www.dropbox.com/developers/apps → Create app → Scoped access → App folder.
2. Permissions: files.content.write en files.content.read → Submit.
3. Settings → OAuth 2 → Redirect URIs: het adres van je Kasboek, bijv.
   https://serenanova.github.io/kasboek/  (met slash aan het eind).
4. App key kopiëren → Kasboek → Instellingen → Dropbox → plakken → Koppelen.
